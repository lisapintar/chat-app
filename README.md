# Chat App Laravel

Aplikasi chat realtime berbasis Laravel 12 dan Laravel Reverb.

## Fitur
- Login & Register
- Private Chat
- Group Chat
- Online Status
- Realtime Message
- Laravel Reverb WebSocket

## Teknologi
- Laravel 12
- MySQL
- Laravel Reverb
- Laravel Echo
- Vite

## Cara Menjalankan

```bash
composer install
npm install
php artisan migrate
php artisan serve
php artisan reverb:start
npm run dev
